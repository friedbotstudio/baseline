- Path: `.claude/skills/swarm-dispatch/worktree-safety.mjs` (`assertWorktreeWaveSafety`) + `swarm_wave_audit.mjs` (`auditWave`) + `parse_worker_result.mjs` (`parseWorkerResult`); `.claude/skills/swarm-plan/validate.mjs` (`execution` field); `.claude/skills/spec-lint/lint.mjs` (`checkApiSurfacePinned`).
- Trap: multi-wave swarm plans under WORKTREE isolation are unsupported BY DESIGN — do not try to "make them work." The Agent tool owns each worktree's base commit and forks from a stale ref (observed: the 0.19.0 release commit, 17 behind HEAD), and `swarm_merge.mjs` applies wave output to the working tree WITHOUT committing, so wave-N+1 worktrees never see wave-N output. This is an Agent-tool constraint, not a baseline bug (confirmed twice: the `-424f` build and the `-e3f2` research phase). Baseline can only REFUSE multi-wave-under-worktree and steer to shared mode (`assertWorktreeWaveSafety` returns `{ok:false}`), not fix it.
- Mitigation (shipped as `-e3f2`, swarm-mode first-run hardening): **D1** worktree = single-wave only + fail-fast guard. **D2** `swarm_wave_audit.auditWave` is a post-wave diff-audit run in shared mode that checks wave changes against the union write_set INDEPENDENTLY of `swarm_boundary_guard`'s `.claude/` exemption — closing the [[swarm-boundary-guard-wave-scoped]] blind spot for baseline self-dev under `.claude/skills/**`. **D4** `parseWorkerResult` flags a worker final message lacking a `{task_id,status:done}` final line (or `status:failed`/trailing prose) as incomplete → resume-or-main-context, never silently passed. **D5** `validate.mjs` REQ now includes `execution: worker-safe|needs-main-context` so the plan classifies worker-safe vs needs-main-context UP FRONT (gate-B sees the split). **D7** `checkApiSurfacePinned` advisory: a swarm-bound spec (≥ `swarm.min_tasks_worth_swarming` Components) with an empty Contracts table is flagged so decomposition is complete pre-dispatch. The `-e3f2` umbrella (D1–D7; D3+D6 shipped earlier as `swarm-d3d6-hardening`) is now closed. Tests: `tests/swarm-first-run-hardening.test.mjs` (15).
