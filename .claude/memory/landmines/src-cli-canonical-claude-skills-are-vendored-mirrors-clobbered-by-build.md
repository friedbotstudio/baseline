- Path: `src/cli/{workflows-validator,workflows-validator-invariants,workflows-validator-predicates,track-tasklist-materializer,workflow-migrator}.js` (CANONICAL) vs `.claude/skills/{triage,harness}/*.js` (MIRRORS). Sync: `scripts/build-template.sh` Stage 0b `sync_vendored_mirror()` runs a plain `cp "$src" "$dst"`. Guard: `tests/vendored-mirror-bytes.test.mjs` asserts byte-equality per pair. Tests import from `src/cli/` (see `tests/byte-equivalent-migration.test.mjs`).
- Trap: these five `.js` modules LOOK like editable skill code sitting under `.claude/skills/`, but they are build-time COPIES. A hand-edit to the `.claude/skills/` mirror is SILENTLY CLOBBERED the next time `build-template.sh` runs (which every baseline-file-touching workflow runs for the manifest rehash). A spec write_set that names the `.claude/skills/triage/*.js` copy names a DERIVED artifact — the implement worker edits it, the mandatory build overwrites it, tests go red with no obvious cause in the diff. This cost a spec amendment mid-workflow in `power-track-completion` (2026-07-09): the approved write_set listed `.claude/skills/triage/workflows-validator-{predicates,invariants}.js`; the scenario tick caught that the tests import from `src/cli/` and the mirror is regenerated.
- This is the THIRD derived-artifact class in the repo; the other two are in [[constitutional-amendment-tripwires-headroom-seedmirror-python3ledger]]: (a) `src/{seed,CLAUDE}.template.md` ← `scripts/sync-constitution-mirror.mjs --write` (seed is a §16-carve-out SPLICE, CLAUDE a full byte-copy); (b) `obj/template/**` ← `build-template.sh` (gitignored). Rule for all three: edit the SOURCE, run the generator, never hand-edit the derived copy.
- Mitigation: when a change touches predicate vocabulary, I11 invariants, the materializer, or the migrator, edit ONLY the `src/cli/` file, then run `bash scripts/build-template.sh` (Stage 0b copies + manifest rehash). Confirm with `cmp src/cli/<f>.js .claude/skills/{triage,harness}/<f>.js` before commit. During `/triage` and `/spec`, resolve any `.claude/skills/**/*.js` in a proposed write_set against `src/cli/` — if a same-named source exists there, the write_set is naming the mirror.
- Proposed structural fix (backlog): a header comment on each derived file (`// DERIVED — edit src/cli/<f>.js; regenerated by build-template.sh Stage 0b`). All three derived classes share the root cause: nothing at the derived file's own source marks it as derived.
